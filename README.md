# Retail Sales Analysis Using Microsoft Excel

## Project Overview
This project analyses a simulated Indian retail sales dataset using Microsoft Excel to identify sales trends, product performance, and city-level performance.

## Tools Used
- Microsoft Excel
- Excel Tables and formulas
- PivotTables and PivotCharts
- Excel Dashboard

## Data Cleaning
- Checked for duplicate Order IDs.
- Checked for missing values in customer names, product names, and sales.
- Standardised customer names and payment-mode text.
- Inspected data types before analysis.

## Key Performance Indicators
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Units Sold
- Average Order Value

## Analysis Performed
- Monthly sales trend analysis
- Product sales and profit comparison
- City-level sales and profit analysis
- Interactive visual reporting through an Excel dashboard

## Initial Findings
- Backpack was identified as the highest-sales product.
- Mouse was identified as the highest-profit product.
- Ahmedabad was identified as the city with the highest sales.

These findings are based on a simulated practice dataset and should be validated against the final workbook before publication.

## Business Objective
The objective is to demonstrate how Excel can be used to clean data, calculate business KPIs, analyse sales performance, and communicate insights through a dashboard.
